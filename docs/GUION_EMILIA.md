# Guion de voz de Emilia

> Las frases que dicen Emilia, Tito y los vecinos del barrio. Define la **personalidad del juego** y sirve de base para la grabación con actores de voz.
> Complementa [MUNDO_Y_EXPERIENCIA.md](MUNDO_Y_EXPERIENCIA.md). Octubre 2026. Versión 1.

---

## 1. Cómo habla Emilia

| Regla | Ejemplo bien | Ejemplo a evitar |
|---|---|---|
| **Frases cortas:** 3 a 8 palabras | *"¡Mira, una M!"* | *"Ahora vamos a observar con atención esta letra que se llama M"* |
| **Positiva siempre** | *"¡Casi! Probemos otra vez"* | *"Incorrecto"*, *"Mal"*, *"No"* |
| **Elogia el esfuerzo** | *"¡Lo intentaste hasta lograrlo!"* | *"¡Eres muy inteligente!"* |
| **Sin género del niño** | *"¡Qué bueno verte!"*, *"¿Empezamos?"* | *"¿Estás listo?"*, *"¡Bienvenida!"* |
| **Pregunta e invita** | *"¿Me ayudas a contar?"* | *"Cuenta las manzanas"* |
| **Humor suave** | *"¡Uy, me confundí yo!"* | Burlas o sarcasmo |
| **Español neutro y cálido** | *"¡Qué entretenido!"* | Modismos muy locales en la versión base |

**Sobre el nombre del niño:** las frases grabadas no incluyen el alias, porque no se puede grabar cada nombre. El juego muestra el avatar del niño en pantalla cuando Emilia le habla. A futuro se puede grabar una lista de los apodos más comunes (Tomi, Sofi, Benja, Agus…) como clips aparte.

**Sobre el género:** todas las frases están escritas para que sirvan a cualquier niño o niña, sin necesidad de preguntar su género.

### Notas para la grabación

- Cada frase tiene un **código** (por ejemplo, `SAL-01`) que será el nombre del archivo de audio.
- `{palabra}`, `{letra}`, `{numero}`, `{animal}` indican piezas que se graban por separado y se unen al reproducir.
- Grabar **2 o 3 tomas** con energía distinta: tranquila, alegre y muy alegre.
- Etiquetas de tono: 😊 alegre · 🤗 cálida · 🤫 tranquila · 🤩 emocionada · 🤭 chistosa.
