# Guiones de los personajes

> Ficha y guion de cada personaje del barrio. Emilia tiene el guion más completo porque es quien crea el lazo con el niño ([EMILIA_COMPANERA.md](EMILIA_COMPANERA.md)).
> Amplía las frases base de [GUION_EMILIA.md](GUION_EMILIA.md). Octubre 2026. Versión 1, para revisar con la educadora.

**Convenciones**
- `{color_favorito}`, `{animal_favorito}`, `{comida_favorita}`, `{letra}`, `{palabra}`, `{numero}`: piezas variables que vienen de la memoria o de la actividad.
- **Niño:** lo que el niño hace (tocar una imagen, un gesto).
- Las frases nunca asumen si el niño es niño o niña.
- Tono: 😊 alegre · 🤗 cálida · 🤫 tranquila · 🤩 emocionada · 🤭 chistosa.

## 1. Emilia

### Ficha

| | |
|---|---|
| **Edad** | 6 años (un poco mayor que el niño: alguien a quien admirar, pero cercana) |
| **Vive con** | Su mamá, su papá y su abuela Nina, en una casa amarilla del barrio |
| **Le encanta** | Pintar, los animales, cantar inventando canciones, preguntar "¿por qué?" |

## 2. Tito, el pudú

### Ficha

| | |
|---|---|
| **Quién es** | El pudú de Emilia. El pudú es el ciervo más pequeño del mundo y vive en el sur de Chile y Argentina. |
| **Personalidad** | Tímido, tierno, curioso y muy cariñoso. Se asusta fácil, pero es valiente con sus amigos. |
| **Cómo se comunica** | **No habla.** Solo sonidos cortos y gestos. El niño "entiende" lo que siente. |
| **Su rol** | El **compañero emocional**: consuela, celebra, respira con el niño y le da ternura al juego. |
| **Le gusta** | Las hojas tiernas, que le rasquen detrás de las orejas, dormir la siesta |
| **Le asusta** | Los truenos y los ruidos fuertes |

### Guion de gestos y sonidos

| Situación | Sonido | Gesto |
|---|---|---|
| Saluda al niño | "¡Pip!" | Mueve las orejas y se acerca |
| El niño le rasca las orejas (toca a Tito) | "Mmmm…" | Cierra los ojos de gusto |
| Acierto | "¡Piu!" | Salto pequeño |
| Celebración grande | "¡Piu-piu-piu!" | Varios saltos y una vuelta |
| El niño está triste | Suspiro suave | Se acerca y apoya la cabeza en el niño |
| Respiración | Inspira y suelta el aire | Infla el pecho como globo y lo suelta |
| Curiosidad | "¿Mmm?" | Inclina la cabeza |
| Risa | "¡Ji-ji-ji!" | Se tapa la cara con las patas |
| Sueño | Bostezo | Se acurruca |
| Miedo (truenos) | "¡Iiip!" | Se esconde detrás de Emilia |
| Despedida | "Pip, pip" | Mueve una patita |

**Interacción especial:** el niño puede tocar a Tito en cualquier momento. Siempre responde con cariño. Si lo toca muchas veces, se ríe y da una vuelta.
